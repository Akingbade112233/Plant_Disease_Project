# Plant_Disease_Project


Plant Disease Detection Using CNN

A deep learning project that uses a Convolutional Neural Network (CNN) to identify plant diseases from leaf images. The model is trained using TensorFlow/Keras and deployed through a Streamlit web application.

Features

- Upload a plant leaf image.
- Preprocess the image for model prediction.
- Use a trained CNN model to predict the plant disease.
- Display the prediction through a simple Streamlit interface.

Technologies Used

- Python
- TensorFlow / Keras
- Streamlit
- OpenCV
- NumPy
- PIL

Running the Application Locally

1. Clone this repository.

2. Install the required dependencies:
   
   "pip install -r requirements.txt"

3. Run the application:
   
   "streamlit run app.py"

Project Status

The application runs locally. Deployment and further model evaluation are in progress.
